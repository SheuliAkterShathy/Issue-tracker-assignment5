1️⃣ What is the difference between var, let, and const?

Answer: var, let, and const are used to declare variables in JavaScript. The main differences are in scope, redeclaration, reassignment, and hoisting.

var → function-scoped, can be redeclared and reassigned.
let → block-scoped, cannot be redeclared in the same scope, but can be reassigned.
const → block-scoped, cannot be redeclared or reassigned after initialization.


2️⃣ What is the spread operator (...)?

Answer: The spread operator (...) is a powerful JavaScript syntax introduced in ES6.
“The spread operator (...) is used to expand or unpack the elements of an array or the properties of an object into another array or object.”


3️⃣ What is the difference between map(), filter(), and forEach()?

Answer: map(), filter(), and forEach() are array methods, but they are used for different purposes. 

map() creates a new array by transforming each element.

filter() creates a new array containing only the elements that satisfy a condition.

forEach() simply executes a function for each element without returning a new array.



4️⃣ What is an arrow function?

Answer: An arrow function is a short and modern way to write function expressions in JavaScript using the => symbol.

It was introduced in ES6. Arrow functions are commonly used for callbacks and they also have a different behavior for the 'this' keyword.


5️⃣ What are template literals?

Answer: Template literals are string literals in JavaScript enclosed by backticks (`) instead of quotes.

They were introduced in ES6 (ECMAScript 2015) to make string handling cleaner and easier to read compared to traditional concatenation.
